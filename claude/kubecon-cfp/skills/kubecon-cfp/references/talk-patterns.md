## Title Patterns (from accepted talks)

### 1. Problem at Scale
- "Reducing Cross-Zone Egress at Spotify"
- "Managing 7K+ Clusters"
- "Taming 50 Billion Time Series"
- Template: `[Verb]ing [Problem] at [Company/Scale]`

### 2. Clever Wordplay/Puns
- "CEL-Ebrating Simplicity"
- "GitOops... I Did It Again!"
- Template: `[Pun on Tech]: [What It Actually Covers]`

### 3. Journey/Evolution
- "From Metal To Apps: LinkedIn's Platform"
- Template: `From [Before] to [After]: [How/Who]`

### 4. Provocative/Contrarian
- "Why Kubernetes Is Inappropriate for Platforms"
- "Is GitOps a Broken Experience?"
- Template: `[Contrarian Claim] — [Evidence]`

### 5. Scale Numbers
- "Managing 7K+ Clusters"
- "Taming 50 Billion Time Series"
- Template: `[Number] [Things]: [What We Did/Learned]`

### 6. Pop Culture
- "Dungeons and Deployments"
- "Choose Your Own Adventure"
- Template: `[Pop Culture Ref]: [Technical Reality]`

### 7. Question Format
- "Is GitOps a Broken Experience?"
- Template: `[Provocative Question About Assumed Best Practice]`

## Optimal Formula
`[Attention Hook]: [Specific Technical Detail] [at Company/Scale]`

## Topic Trends

### Hot / Growing (target these)
- AI Agents / Agent-Native Infrastructure
- Dynamic Resource Allocation (DRA) for GPUs
- LLM Inference Optimization on K8s
- Platform Engineering + AI convergence
- MCP (Model Context Protocol)
- Slurm + Kubernetes for HPC/AI
- Supply Chain Security (SLSA, Sigstore, VEX)
- Cell-Based Architecture
- Gateway API
- eBPF / Cilium

### Steady (need sharp angle)
- Observability / OpenTelemetry
- Networking / Service Mesh
- Operations / Scaling
- GitOps (Argo/Flux)
- Data / Storage

### Declining (avoid unless strong angle)
- WebAssembly
- Sustainability / Green Computing
- Basic Kubernetes operations
- Serverless (standalone)

## Speaker/Company Patterns

### End Users Get Higher Acceptance
- Vendors: 53% of talks but 74% of speakers
- End Users: 45% of talks but only 24% of speakers
- End-user production stories are disproportionately accepted

### Top End-User Companies (for co-presentation ideas)
Apple, Spotify, CERN, LinkedIn, LEGO Group, Bloomberg, Uber

### What Works
- End-user + vendor co-presenting
- Cross-company collaboration
- First-time speakers (30-40% target)
- Honest failure stories with lessons
- Specific production metrics

### What Gets Rejected
- Sales pitches / product marketing
- Generic introductions
- Previously presented content
- Vague "best practices" without data
- Theory without production validation

## Session Type Strategy

| Type | % of Slots | Competition | Best For |
|------|-----------|-------------|----------|
| Breakout | ~60% | Highest | Deep technical, production stories |
| Lightning | ~15% | Lower | Focused insight, first-time speakers |
| Project Lightning | ~18% | Medium | CNCF project updates |
| Tutorial | ~3% | Low | Hands-on workshops |
| Keynote | ~7% | Invite/committee | High-profile stories |

Lightning talks = best entry point for first-time speakers.
