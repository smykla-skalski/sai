# Output Template (concise note)

```markdown
# 🎬 {title}

**Channel:** {author}
**URL:** {url}
**Duration:** {duration_human} | **Language:** {language}
**Date summarized:** {YYYY-MM-DD}
**Tags:** #youtube #summary #{topic}

## 🎯 TL;DR

One- or two-sentence core thesis of the video.

## 🔑 Key Points

- 📌 Point 1 — supporting detail `[mm:ss]`
- 📌 Point 2 — supporting detail `[mm:ss]`
- 📌 Point 3 — supporting detail
- 📌 Point 4 — supporting detail
- ... (4-6 total, essentials only)

## 💡 Takeaways

- What this means / how to apply
- Connection to [[Related Note]]

## 🔗 Related

[[MOC]], [[Related Topic]]
```

Notes:

- Concise by design — no full "detailed notes" section.
- Skip a section if the transcript yields nothing for it.
- Timestamps come from the script's `chapters` field.
- Keep bullets tight; prefer scannability over prose.
